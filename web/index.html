Por Que Criamos o "Jogando Junto"?

Controles comuns de videogame possuem mais de 16 botões minúsculos e 2 analógicos. Para crianças com paralisia cerebral, atrofia muscular ou dificuldades motoras finas, jogar videogame convencional é fisicamente impossível.

Com o conceito One-Switch Gaming, qualquer toque voluntário (usando a mão aberta, antebraço, pé ou queixo) garante autonomia completa no jogo.

// 1. Leitura do botão com resistor Pull-Up interno (3.3V quando solto)
int leituraAtual = digitalRead(PINO_BOTAO);

// 2. Filtro de Debounce anti-trepidação mecânica (40 ms)
if ((millis() - tempoUltimaMudanca) > TEMPO_DEBOUNCE) {

// 3. CASO A: Botão apertado com força (circuito fechou em LOW / 0V)
  if (estadoEstavelBotao == LOW) {
    digitalWrite(PINO_LED, HIGH);      // Acende o LED azul da placa!
    Serial.println("SPACE:DOWN");      // Dispara comando USB para o jogo!
  }

// 4. CASO B: Botão solto (volta para 3.3V pelo Pull-Up)
  else {
    digitalWrite(PINO_LED, LOW);       // Apaga o LED
    Serial.println("SPACE:UP");        // Libera a tecla de espaço
  }
}

⚡ INPUT_PULLUP

O ESP32 ativa um resistor interno de 45 kΩ ligado aos 3.3V. Enquanto solto, lê 1 (HIGH). Ao encostar no GND, vai a 0 (LOW).

⏱️ Debounce de 40ms

Filtro no firmware que descarta o repique mecânico das placas de papelão antes de enviar o sinal ao jogo.

🔌 Web Serial API

Comunicação direta a 115200 bps pelo cabo USB: latência zero e sem risco de interferência de sinal na feira.
